A small client-side utility built with vanilla HTML, CSS, and JavaScript to calculate cost per unit area across different pizza sizes and topping configurations.

### Features

- **Area & Unit Price Comparison:** Calculates effective price per square inch / centimeter based on diameter input and base pricing.
- **Dynamic Updates:** Immediate calculation without page reloads or external dependencies.
- **Vanilla Implementation:** No frameworks, built directly with semantic HTML and plain JavaScript DOM manipulation.
